# tbank_case_jkh

## Задача
Команда платежей запустила A/B-тест новой формы оплаты ЖКХ с упрощённым (автоматическим) заполнением реквизитов.
**Гипотеза:** новая форма увеличит долю успешных оплат в воронке «Открыл форму → Ввёл реквизиты → Подтвердил платёж → Успешная оплата». 
- Тест проводился 1-30 апреля 2024 г.
- Единица рандомизации - пользователь (клиент). 
- Ключевая метрика - конверсия из шага 1 в шаг 4.

## Цель
Проанализировать результаты А/В-теста и дать рекомендации по внедрению (или отказу от внедрения) новой формы на всех пользователей 

### Структура файла
| Лист | Строк | Описание |
|---|---|---|
| Пользователи | ~1500 | Группы А/В, тип устройства, город |
| Платежи | ~2000 | Попытки оплаты ЖКХ за период теста (воронка по шагам)|

Данные были получены из Excel-таблицы: [data.xlsx](https://github.com/user-attachments/files/32006354/data.xlsx)

### Данные
| Лист | Колонки |
|---|---|
| `Пользователи` | `user_id`, `group`, `age`, `city`, `device_type` |
| `Платежи` | `payment_id`, `user_id`, `group`, `step1_opened`, `step2_entered`, `step3_confirmed`, `step4_success` |

### Этапы анализа
- Разведочный анализ данных (EDA)
- Работа с выбросами и некорректными данными
- Визуализация результатов
- Статистическая проверка гипотез
- Формулировка рекомендаций на основе данных

### Статистически значимые показания после анализа
| Метрика | Значение |
|---|---|
| Абсолютный прирост | +14,62 п.п. |
| Относительный прирост | +22,2% |
| 95% ДИ разности | [+10,20; +19,05] п.п. |
| Z-тест | z = 6,39, p ≈ 1,7×10⁻¹⁰ |
| χ²-тест Пирсона | χ² = 40,78, p ≈ 1,7×10⁻¹⁰ |
